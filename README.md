# 🧮 Portafolio de Calculadoras | Portafolio of Calculators

## 🌟 Descripción del Proyecto

Este repositorio es un portafolio de proyectos que tiene como objetivo principal **demostrar mis habilidades en el desarrollo web front-end y la lógica de programación** a través de la creación de diversas herramientas de cálculo.

Cada calculadora es un proyecto independiente, implementado usando tecnologías web fundamentales, lo que permite observar diferentes enfoques para la:

1.  **Manipulación del DOM** (Document Object Model).
2.  **Validación de entradas** (input validation).
3.  **Implementación de lógica de negocio** (business logic) o fórmulas matemáticas.
4.  **Diseño de interfaz de usuario** (UI/UX) simple y funcional.

En conjunto, este portafolio busca ser una prueba práctica de mi capacidad para tomar requisitos funcionales y convertirlos en soluciones interactivas y accesibles.

## 🎯 Habilidades Demostradas

El desarrollo de este portafolio me ha permitido consolidar y exhibir las siguientes competencias clave:

| Habilidad | Descripción |

## 🛠️ Calculadoras Incluidas

A continuación, se detalla cada una de las herramientas de cálculo que componen este portafolio:

| Nombre del Proyecto | Propósito Funcional | Lógica de Programación Demostrada |
| :--- | :--- | :--- |
| **Calculadora de IMC** | Permite a un usuario obtener su Índice de Masa Corporal (IMC) y clasificar su estado de salud (bajo peso, normal, sobrepeso, etc.). | Uso de la fórmula IMC = peso / (altura²) y aplicación de estructuras condicionales (`if/else` o `switch`) para la clasificación de rangos. |
| **Calculadora de Descuentos** | Calcula el precio final de un artículo tras aplicar un porcentaje de descuento. | Manejo de operaciones porcentuales y manejo de números decimales. |
| **Calculadora de Interés Simple** | Herramienta financiera básica para calcular el interés y el monto total de una inversión o deuda en un período específico. | Aplicación de la fórmula $I = C \cdot R \cdot T$ (Capital x Tasa x Tiempo). |
| **Calculadora Básica (Matemática)** | Una calculadora de 4 operaciones (suma, resta, multiplicación, división). | Manejo de operadores, precedencia de operaciones y gestión del estado de la pantalla de cálculo. |

## 💻 Tecnologías Utilizadas

Todas las herramientas de cálculo en este repositorio están construidas con las bases del desarrollo web:

* **HTML5:** Estructura semántica del contenido.
* **CSS3:** Estilización y presentación visual.
* **JavaScript (Vanilla JS - ES6+):** Lógica funcional y control de la interactividad.
